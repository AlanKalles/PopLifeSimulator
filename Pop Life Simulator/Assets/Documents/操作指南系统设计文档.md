# 操作指南 (Operation Guide) 系统设计文档

## Context

现有的 Spotlight 教程系统难以对非按钮形式或特殊用途的 UI 元素进行高亮指导。需要设计一个全新的"操作指南"系统作为补充方案——通过截图+文字说明的多页面板，为玩家提供更通用的操作指导。该系统与 TutorialMarkerBridge 集成，在特定 marker 触发时自动弹出对应指南，同时支持玩家随时通过集合面板回顾已解锁的指南。

---

## 触发方式（3种）

1. **Marker 触发**：在 `TutorialMarkerBridge` 的 Inspector 中，每个 `MarkerQuestMapping` 新增 `operationGuide` 字段。当 `TutorialEventBus.RaiseMarker()` 触发时自动弹出对应指南。
2. **对话 Sequencer 命令触发**：通过 `ShowGuide(Guide_BuildingBasics)` 在 Dialogue Editor 任意对话节点中使用。
3. **代码直接调用**：`OperationGuideManager.Instance.ShowGuide("guideId")`。

## 新建文件 (6个)

### 1. `Scripts/Data/OperationGuideData.cs` — 数据层

```csharp
namespace PopLife.Data

[CreateAssetMenu(menuName = "PopLife/Guide/OperationGuideData")]
public class OperationGuideData : ScriptableObject
{
    [HideInInspector] public string guideId;        // OnValidate 自动同步为 asset.name
    public string displayName;                       // 面向玩家的显示名称（英文）
    [TextArea] public string description;            // 简要描述（集合面板中显示）
    public Sprite icon;                              // 图标（可选，null时用首页截图）
    public int sortOrder = 100;                      // 排序优先级
    public GuidePage[] pages;                        // 多页内容
}

[Serializable]
public class GuidePage
{
    public Sprite screenshot;                        // 页面截图
    public string title;                             // 页面标题
    [TextArea] public string body;                   // 页面正文
}
```

SO 资产路径：`Resources/ScriptableObjects/OperationGuides/`

### 2. `Scripts/Manager/OperationGuideManager.cs` — 服务层

```csharp
namespace PopLife.Manager  // 单例: OperationGuideManager.Instance

// 状态管理
HashSet<string> unlockedGuideIds;   // 已解锁
HashSet<string> viewedGuideIds;     // 已查看

// ES3 持久化 (文件: OperationGuides.es3)
ES3.Save/Load<List<string>>("guideUnlockedIds" / "guideViewedIds")

// 核心 API
void ShowGuide(string guideId)           // 按ID显示（自动解锁 + 打开面板）
void ShowGuide(OperationGuideData data)  // 按SO引用显示
void UnlockGuide(string guideId)         // 仅解锁不显示
void MarkAsViewed(string guideId)
bool IsUnlocked(string guideId)
bool IsViewed(string guideId)
List<OperationGuideData> GetUnlockedGuides()  // 按sortOrder排序
int GetUnviewedCount()                         // 未读数（红点提示用）

// 事件
event Action<string> OnGuideUnlocked;
event Action<string> OnGuideViewed;
```

### 3. `Scripts/UI/Guide/OperationGuidePanel.cs` — 指南面板

模态面板，CanvasGroup 淡入淡出：
- **上方中央**：screenshotImage (Image)
- **下方中央**：titleText + bodyText (TMP)
- **底部中央**：pageIndicatorText "1 / 5"
- **左右两侧**：prevButton / nextButton（第一页隐藏左，最后页隐藏右）
- **右上角**：closeButton
- **遮罩**：backgroundOverlay (半透明黑)
- **键盘**：A/LeftArrow 上一页，D/RightArrow 下一页，ESC 关闭
- `Show(OperationGuideData, onClose)` 时自动调用 `MarkAsViewed()`

### 4. `Scripts/UI/Guide/GuideCollectionPanel.cs` — 指南集合面板

列表面板，展示所有已解锁指南：
- 从 `OperationGuideManager.GetUnlockedGuides()` 获取数据
- 动态实例化 `GuideCollectionEntry` 预制体
- 空状态提示（无已解锁指南时）
- ESC 关闭，CanvasGroup 淡入淡出
- 监听 `OnGuideUnlocked`/`OnGuideViewed` 自动刷新

### 5. `Scripts/UI/Guide/GuideCollectionEntry.cs` — 集合列表条目

每个条目显示：
- `nameText`：指南显示名称
- `descriptionText`：简要描述
- `iconImage`：图标（icon 或首页截图）
- `newBadge`：未读标记（"NEW"）
- `entryButton`：点击打开对应指南

### 6. `Scripts/DialogueBridge/Sequencer/SequencerCommandShowGuide.cs`

```
Dialogue Sequence: ShowGuide(Guide_BuildingBasics)
```
- 遵循 SequencerCommandSpotlight 模式
- 调用 `OperationGuideManager.Instance.ShowGuide(guideId)` 后立即 `Stop()`

## 修改文件 (3个)

### 1. `Scripts/DialogueBridge/TutorialMarkerBridge.cs`

**MarkerQuestMapping 类** (第 97 行 `[Title("Metadata")]` 前插入)：
```csharp
[Title("Operation Guide")]
[Tooltip("触发此标记时显示的操作指南（可选）")]

```

```csharp
ExecuteGuideAction(mapping);
```

**新增方法** (ExecuteConversationAction 之后)：
```csharp
private void ExecuteGuideAction(MarkerQuestMapping mapping)
{
    if (mapping.operationGuide == null) return;
    OperationGuideManager.Instance?.ShowGuide(mapping.operationGuide);
}
```

## 数据流

```
TutorialEventBus.RaiseMarker(marker)
  → TutorialMarkerBridge.HandleMarkerTriggered()
    → ExecuteGuideAction(mapping)
      → OperationGuideManager.ShowGuide(data)
        → UnlockGuide() + ES3 Save
        → UIManager.ShowOperationGuide(data)
          → OperationGuidePanel.Show(data)
            → MarkAsViewed() + ES3 Save
            → 显示第一页内容
```

## 验证方式

1. **编译检查**：Unity 编辑器无编译错误
2. **SO 创建**：通过 Create → PopLife → Guide → OperationGuideData 创建测试指南资产，填入多页截图和文字
3. **面板测试**：在场景中创建面板预制体，通过 Inspector 连线后运行游戏，调用 `OperationGuideManager.Instance.ShowGuide("测试ID")` 验证面板显示、翻页、关闭
4. **Marker 集成**：在 TutorialMarkerBridge Inspector 中为某个 marker 配置 operationGuide 引用，触发 marker 后验证指南自动弹出
5. **持久化**：关闭游戏后重新打开，验证 GuideCollectionPanel 中已解锁指南仍在列表中
6. **Sequencer 命令**：在 Dialogue Editor 中使用 `ShowGuide(测试ID)` 验证命令正常工作
