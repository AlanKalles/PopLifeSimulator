# 货架列表面板设置指南 v3.0

## 更新说明 | Update Notes

**v3.0 重大更新**（手动配置模式）：
- ✅ **SelectPage 按钮改为手动创建**：在 Unity 中完全自定义位置、大小、样式
- ✅ **Inspector 配置筛选范围**：每个按钮独立设置 FilterValue
- ✅ **所见即所得**：设计师完全控制 UI 布局
- ✅ **保留 Alpha Hit Test**：支持非矩形交互区域
- ✅ **Category 按钮保持程序生成**：视觉统一，自动排列

## 概述 | Overview

本指南将帮助你创建一个专用的货架建造面板，带有双重筛选系统（SelectPage + ProductCategory）。

**核心特性**：
- **SelectPage 按钮**：手动创建，自定义布局，使用 Alpha Hit Test 检测非矩形区域
- **Category 按钮**：程序生成，视觉统一，自动排列
- **统一管理**：通过 `IFilterButton` 接口统一管理两种按钮

7. 运行时自动注册到 FilterToggleGroup

## Part 1: 手动创建 SelectPageButton（核心步骤）

### Step 1.1: 创建按钮 GameObject

1. Hierarchy 右键 → **UI → Image**，命名为 `SelectPageButton_Body`
2. **设置位置**（自由摆放，根据你的 UI 设计）：
   - 例如：Position X: -800, Y: 300
   - Width: 150, Height: 150
3. **设置 Sprite**：
   - 拖入带透明通道的 Body 图片（PNG 32-bit）
   - Color: White (255, 255, 255, 255)
   - Raycast Target: ✓

### Step 1.2: 添加 SelectPageButton 脚本

选中 `SelectPageButton_Body`：
- **Add Component** → `SelectPageButton`

**配置 Inspector 字段**：

#### **Filter Configuration** ⭐ 核心配置
- **Is All Button**: ✗（不勾选，这是 Body 按钮）
- **Filter Page**: **Body**（从下拉菜单选择）

#### **UI References**
- **Button Image**: 拖入自身 Image 组件
- **Highlight Overlay**: 留空（可选，稍后添加）

#### **Alpha Hit Test Settings**
- **Alpha Hit Test Minimum Threshold**: `0.1`
  - 表示只有透明度 > 10% 的像素区域才响应点击
  - 调整此值来控制点击灵敏度

#### **Visual Settings**
- **Normal Color**: `(255, 255, 255, 255)` 白色
- **Selected Color**: `(128, 179, 230, 255)` 蓝色高亮
- **Hover Color**: `(230, 230, 230, 255)` 浅灰色

#### **Highlight Overlay Settings**
- **Use Highlight Overlay**: ✓（推荐）
- **Overlay Normal Color**: `(255, 255, 255, 0)` 透明
- **Overlay Selected Color**: `(128, 179, 230, 128)` 半透明蓝色
- **Overlay Hover Color**: `(255, 255, 255, 51)` 半透明白色

### Step 1.3: 添加高亮叠加层（可选但推荐）

如果勾选了 `Use Highlight Overlay`：

1. 右键 `SelectPageButton_Body` → **UI → Image**，命名为 `HighlightOverlay`
2. **RectTransform**：
   - Anchor: Stretch-Stretch
   - Left: 0, Right: 0, Top: 0, Bottom: 0
3. **Image**：
   - Sprite: 与父对象相同（或留空）
   - Color: `(255, 255, 255, 0)` 完全透明
   - Raycast Target: ✗ **不勾选**
4. 在 SelectPageButton 脚本中拖入此 Image 到 `Highlight Overlay` 字段

### Step 1.4: 测试 Alpha Hit Test

1. 进入 Play 模式
2. 鼠标移动到 Body 按钮的身体部分 → 应该显示高亮
3. 鼠标移动到透明区域 → 高亮消失（点击穿透）

### Step 1.5: 重复创建其他按钮

按照 Step 1.1-1.3 创建其他按钮：
- `SelectPageButton_Head`（Filter Page = **Head**）
- `SelectPageButton_Front`（Filter Page = **Front**）
- `SelectPageButton_Back`（Filter Page = **Back**）
- `SelectPageButton_MedicineBox`（Filter Page = **MedicineBox**）
- `SelectPageButton_Kinky`（Filter Page = **Kinky**）
- `SelectPageButton_All`（**Is All Button = ✓**，Filter Page 忽略）

⚠️ **注意**：每个按钮的位置、大小、Sprite 都可以完全不同！

## Part 2: 准备 Sprite 资源（重要）

### Step 2.1: Sprite 要求

SelectPage 按钮使用 Alpha Hit Test，需要带有透明通道的 PNG 图片：

**Body 按钮示例**：
```
┌──────────────┐
│  ░░░░░░░░    │  ← 透明区域（Alpha < 0.1，点击穿透）
│   ████████   │  ← 不透明区域（Alpha >= 0.1，响应点击）
│   ██人体██   │
│   ████████   │
│  ░░░░░░░░    │  ← 透明区域（点击穿透）
└──────────────┘
```

**关键原理**：
- 像素 Alpha >= 0.1 → 响应点击
- 像素 Alpha < 0.1 → 忽略点击（点击穿透）

### Step 2.2: 导入 Sprite

1. 将准备好的 PNG 图片拖入 `Assets/Art/UI/SelectPageIcons/`
2. 选中图片，在 Inspector 中配置：
   - **Texture Type**: Sprite (2D and UI)
   - **Sprite Mode**: Single
   - **Pixels Per Unit**: 100
   - **Filter Mode**: Bilinear
   - **Compression**: None 或 Low Quality（保留 Alpha 通道质量）
   - **Alpha Is Transparency**: ✓
   - **Read/Write Enabled**: ✓ **（重要：Alpha Hit Test 需要读取像素数据）**
3. 点击 **Apply**

准备以下 Sprite：
- `body_icon.png`
- `head_icon.png`
- `front_icon.png`
- `back_icon.png`
- `medicinebox_icon.png`
- `kinky_icon.png`
- `all_pages_icon.png`

   - Spacing: 5
   - Child Alignment: Middle Left
   - Child Control Size: Width ✗, Height ✓

### Step 3.5: 创建 ScrollView（货架网格）

1. 右键 `ShelfListPanel` → **UI → Scroll View**，命名为 `ScrollView`
2. **RectTransform**：
   - Anchor: Stretch-Stretch
   - Left: 210, Right: 10, Top: 110, Bottom: 10

3. **Scroll Rect** 配置：
   - Horizontal: ✗
   - Vertical: ✓

4. **删除** `Scrollbar Horizontal`

5. 配置 `Content`：
   - **Add Component** → **Grid Layout Group**：
     - Cell Size: 80 x 80
     - Spacing: 10 x 10
     - Start Corner: Upper Left
     - Start Axis: Horizontal
     - Constraint: Fixed Column Count = 3
   - **Add Component** → **Content Size Fitter**：
     - Vertical Fit: Preferred Size

将 `ShelfTooltip` 预制体拖入 `ShelfListPanel` 作为子对象（参考原设置指南）

## Part 5: 工作原理详解

### "All" 按钮的实现

```csharp
// SelectPageButton 配置
SelectPageButton_All:
  Is All Button = ✓  →  FilterValue = null

// 筛选逻辑（ShelfListPanel.cs）
bool ShouldShowShelf(ShelfArchetype shelf)
{
    // 第一层：SelectPage 筛选
    if (selectedSelectPage != null) // 非 "All"
    {
        if (!shelf.selectPages.Contains(selectedSelectPage.Value))
            return false;
    }
    // selectedSelectPage == null 时，显示所有货架

    // 第二层：ProductCategory 筛选
    if (selectedCategory != null)
    {
        if (shelf.category != selectedCategory.Value)
            return false;
    }

    return true;
}
```

### Alpha Hit Test 工作原理

```
用户点击 SelectPage 按钮 → Unity 检测点击位置像素的 Alpha 值

if (像素 Alpha >= alphaHitTestMinimumThreshold)  // 默认 0.1
{
    触发点击事件 → SelectPageButton.OnPointerClick()
}
else
{
    点击穿透，忽略此按钮
}
```

### 按钮注册流程

```csharp
// ShelfListPanel.InitializeSelectPageButtons()
foreach (var button in selectPageButtons)  // 遍历手动拖入的数组
{
    button.Initialize((clickedToggle) =>
    {
        selectPageToggleGroup.OnToggleClicked(clickedToggle);
    });

    selectPageToggleGroup.RegisterToggle(button);  // 注册到组
}

selectPageToggleGroup.SelectAll();  // 默认选中 "All" 按钮（FilterValue == null）
```

## Part 6: 测试流程

### Step 6.1: 准备测试数据

确保 `Resources/ScriptableObjects/BuildingArchetype/` 中有 ShelfArchetype，并设置：
- `category`（ProductCategory 枚举）
- `selectPages`（SelectPage[] 数组）

### Step 6.2: 测试 Alpha Hit Test

1. **运行游戏**
2. **打开面板**
3. **测试 SelectPage 按钮**：
   - 点击 Body 按钮的身体部分 → 应该响应，按钮高亮
   - 点击 Body 按钮的透明区域 → 应该不响应（点击穿透）
   - 鼠标悬停在图标上 → 显示悬停高亮效果
   - 鼠标移到透明区域 → 高亮消失

### Step 6.3: 测试筛选逻辑

1. **测试 "All" 按钮**：
   - 点击 "All" → 显示所有货架
2. **测试 SelectPage 筛选**：
   - 点击 "Body" → 只显示 `selectPages` 包含 Body 的货架
   - 点击 "Head" → 只显示 `selectPages` 包含 Head 的货架
3. **测试 ProductCategory 筛选**：
   - 选择 SelectPage = "Body"
   - 点击 Category = "Condom" → 只显示 Body + Condom 的货架
4. **测试单选行为**：
   - 点击 "Body" → Body 高亮
   - 点击 "Head" → Head 高亮，Body 恢复正常
   - 同时只能有一个 SelectPage 按钮被选中

### Step 6.4: 调试 Alpha Hit Test

如果 Alpha Hit Test 不工作：
1. **检查 Sprite 导入设置**：
   - `Read/Write Enabled` 必须勾选
   - `Alpha Is Transparency` 必须勾选
2. **检查脚本配置**：
   - `alphaHitTestMinimumThreshold` 值（推荐 0.1）
   - `buttonImage.raycastTarget` 必须为 true
3. **检查图片质量**：
   - 使用原始 PNG 32-bit 格式
   - Compression 设置为 None 或 Low Quality
4. **Scene 视图调试**：
   - 查看 Raycast Target 和 Hit Area

## Part 7: 常见问题 FAQ

### Q: SelectPage 按钮整个矩形区域都响应点击，Alpha Hit Test 没生效？
A:
1. 检查 Sprite 的 `Read/Write Enabled` 是否勾选
2. 检查 `alphaHitTestMinimumThreshold` 值是否正确设置
3. 确保图片有正确的透明通道（Alpha 通道）
4. 在 Scene 视图中检查图片是否正确显示透明区域

### Q: 如何调整 SelectPage 按钮的位置？
A: 直接在 Scene 视图或 Inspector 中拖动 RectTransform 的 Position，完全自由控制！

### Q: 能否让 SelectPage 按钮使用 Layout Group 自动排列？
A: 可以！在 `SelectPageButtonContainer` 上添加 Vertical Layout Group，按钮会自动排列。但这样会失去自由布局的优势。

### Q: 如何添加新的 SelectPage 类型？
A:
1. 在 `ShelfArchetypes.cs` 中扩展 `SelectPage` 枚举（添加新值）
2. 在 Unity 中手动创建新的 SelectPageButton GameObject
3. 配置 `Filter Page` 为新添加的枚举值
4. 在 ShelfListPanel 的 `selectPageButtons` 数组中添加此按钮

### Q: "All" 按钮如何工作？
A: 勾选 `Is All Button = ✓` 后，按钮的 `FilterValue` 会自动返回 `null`，表示"不筛选任何 SelectPage"，即显示所有货架。

### Q: 能否移除 SelectPageButtonContainer？
A: 可以！按钮可以直接放在 ShelfListPanel 下，或任意其他位置。只要在 `selectPageButtons` 数组中拖入即可。

### Q: Category 按钮能否也改为手动创建？
A: 可以参考 SelectPageButton 的方式修改 FilterToggleButton，但当前设计假设 Category 按钮视觉统一，程序生成更方便。

## Part 8: 性能优化建议

### Sprite 资源优化

1. **使用 Sprite Atlas**：
   - 将所有 SelectPage Sprite 打包到一个 Atlas
   - 减少 Draw Call 和内存占用

2. **合理设置压缩**：
   - 对于需要 Alpha Hit Test 的 Sprite，使用 RGBA Compressed ETC2（Android）或 RGBA Compressed ASTC（iOS）
   - 避免使用 None 压缩（文件过大）

3. **调整 Sprite 尺寸**：
   - 256x256 足够用于大部分按钮
   - 512x512 用于高清屏或需要放大的按钮

### 运行时优化

1. **延迟初始化**：
   - 当前已实现：面板在首次打开时才初始化（`InitializePanel()`）

2. **避免频繁重建**：
   - 使用 `SetActive()` 显示/隐藏 Item，而非销毁重建
