# 滚动播报条 - 随机新闻系统使用指南

## 概述

本文档说明如何配置和使用滚动播报条的随机新闻插入功能。该功能允许在顾客结账消息之间随机穿插播放新闻文本。

---

## 功能特性

- ✅ **自动随机插入**：新闻会在设定的时间间隔内随机插入消息队列
- ✅ **可配置间隔**：支持设置最小/最大插入间隔（最短5秒）
- ✅ **可编辑文本库**：通过友好的编辑器界面添加/管理新闻文本
- ✅ **无缝穿插**：新闻自动排队，与结账消息混合播放
- ✅ **运行时控制**：可通过代码动态启用/禁用、添加新闻

---

## 快速设置步骤

### 第一步：创建新闻库资产

1. 在Unity编辑器中，右键点击 `Project` 面板
2. 选择 **Create → PopLife → UI → News Library**
3. 命名为 `DefaultNewsLibrary`（或自定义名称）
4. 将资产保存到合适的文件夹（推荐：`Assets/Resources/ScriptableObjects/UI/`）

### 第二步：配置新闻内容

1. 选中刚创建的 `NewsLibrary` 资产
2. 在 Inspector 面板会看到自定义编辑器界面

#### 快速添加示例新闻

点击 **"Add Sample News (English)"** 按钮，会自动添加10条示例英文新闻。

#### 手动添加新闻

1. 展开 **"Add New News"** 折叠栏
2. 在文本框中输入新闻内容（支持多行）
3. 点击 **"Add News"** 按钮
4. 重复步骤添加更多新闻

#### 编辑现有新闻

在 **"Current News Items"** 列表中：
- **编辑文本**：直接在文本框中修改
- **删除新闻**：点击 `Delete` 按钮
- **调整顺序**：使用 `▲` `▼` 按钮移动位置
- **查看字符数**：底部显示字符统计

### 第三步：配置时间间隔

在 **Timing Settings** 区域：

- **Min Insert Interval (seconds)**：最小插入间隔（默认5秒）
- **Max Insert Interval (seconds)**：最大插入间隔（默认15秒）

系统会在这个范围内随机选择下次插入的等待时间。

**示例**：
```
Min: 5秒，Max: 15秒
→ 可能在 5.2秒、10.8秒、14.3秒 等时间点插入新闻
```

### 第四步：关联到ScrollingMessageBar

1. 在 Hierarchy 中找到 **MessageBar** GameObject
2. 选中后查看 Inspector 中的 **Scrolling Message Bar (Script)** 组件
3. 在 **News Settings** 区域：
   - **News Library**：拖入你创建的 `NewsLibrary` 资产
   - **Enable Random News**：勾选启用（默认已勾选）

### 第五步：测试运行

1. 进入 Play 模式
2. 观察 Inspector 中的 **Debug Info** 区域：
   - `Current Queue Count`：当前队列消息数
   - `Next News Time`：距离下次插入新闻的倒计时

3. 手动测试（在 MessageBar 的 Inspector 中右键点击组件）：
   - **Test - Insert Random News Now**：立即插入一条随机新闻
   - **Test - Toggle Random News**：切换随机新闻开关
   - **Test - Add Sample Messages**：添加测试结账消息

## 运行时代码控制

### 手动插入新闻

```csharp
// 获取 ScrollingMessageBar 引用
ScrollingMessageBar messageBar = GetComponent<ScrollingMessageBar>();

// 插入自定义新闻
messageBar.InsertNewsManually("Breaking: New product launched today!");
```

### 启用/禁用随机新闻

```csharp
// 启用随机新闻
messageBar.SetRandomNewsEnabled(true);

// 禁用随机新闻
messageBar.SetRandomNewsEnabled(false);
```

### 运行时更换新闻库

```csharp
// 加载另一个新闻库
NewsLibrary specialNewsLibrary = Resources.Load<NewsLibrary>("SpecialNewsLibrary");

// 设置到MessageBar
messageBar.SetNewsLibrary(specialNewsLibrary);
```

### 从外部添加新闻到库

```csharp
NewsLibrary library = GetComponent<ScrollingMessageBar>().newsLibrary;

// 添加新闻
library.AddNews("Custom news from code");

// 移除指定索引的新闻
library.RemoveNewsAt(0);

// 清空所有新闻
library.ClearAllNews();
```

## 工作流程说明

### 系统运行流程

```
游戏启动
  ↓
ScrollingMessageBar.Awake()
  → 初始化新闻定时器（获取随机间隔）
  ↓
ScrollingMessageBar.Update()
  → 定时器累加（newsTimer += Time.deltaTime）
  → 检查是否到达间隔时间
  ↓
[时间到]
  → InsertRandomNews()
  → 从NewsLibrary随机选择一条新闻
  → EnqueueMessage(randomNews)
  → 重置定时器（获取新的随机间隔）
  ↓
消息队列
  → 按FIFO顺序播放（新闻与结账消息混合）
```

### 消息混合示例

假设设置：`Min: 5秒，Max: 10秒`

```
时间轴：
0s   → 顾客A结账："Alice spent $150..."
3s   → 顾客B结账："Bob spent $89..."
7s   → [随机新闻插入] "Breaking News: Local..."
10s  → 顾客C结账："Charlie spent $234..."
15s  → [随机新闻插入] "Economy Update: Consumer..."
17s  → 顾客D结账："David spent $120..."
```

## 调试与优化

### Inspector调试信息

在Play模式下，查看 **ScrollingMessageBar** 的 Inspector：

- **Current Queue Count**：当前队列中的消息数量
  - 正常范围：0 ~ 10
  - 如果持续为0，检查是否有顾客结账或新闻库是否为空

- **Next News Time**：距离下次插入新闻的倒计时（秒）
  - 正常范围：0 ~ maxInsertInterval
  - 如果一直不变化，检查`Enable Random News`是否勾选

### 常见问题

#### 1. 新闻不插入？

**检查清单**：
- ✅ NewsLibrary已分配到MessageBar
- ✅ Enable Random News已勾选
- ✅ NewsLibrary中至少有1条新闻
- ✅ Min/Max Interval设置合理（至少1秒）

#### 2. 新闻插入太频繁/太稀疏？

**调整方法**：
- 太频繁 → 增加 `Min Insert Interval` 和 `Max Insert Interval`
- 太稀疏 → 减小 `Min Insert Interval` 和 `Max Insert Interval`

**推荐设置**：
- 慢节奏：`10s ~ 30s`
- 正常节奏：`5s ~ 15s`
- 快节奏：`3s ~ 8s`

#### 3. 新闻重复播放同一条？

**原因**：NewsLibrary中只有1条新闻

**解决**：添加更多新闻到库中（建议至少5-10条）

#### 4. 编辑器界面不显示？

**检查**：是否正确创建了 `NewsLibraryEditor.cs` 脚本并放置在 `Assets/Scripts/Editor/` 文件夹中

## 最佳实践

### 新闻内容设计

1. **长度适中**：建议单条新闻 40-80 个字符
   - 太短：滚动太快，玩家看不清
   - 太长：占用队列时间过长

2. **主题相关**：新闻内容应与游戏主题相关
   - ✅ 推荐：商业新闻、行业动态、市场趋势
   - ❌ 避免：无关政治、敏感话题

3. **语言风格**：保持游戏氛围
   - 正式新闻风格："Breaking News: ...", "Report: ..."
   - 幽默调侃风格："Did you know? ...", "Fun Fact: ..."

### 时间间隔设计

1. **根据游戏节奏调整**：
   - 高峰期（顾客多）→ 使用较长间隔（减少干扰）
   - 低峰期（顾客少）→ 使用较短间隔（保持活跃）

2. **避免过度重复**：
   - 新闻数量应 ≥ 5条（建议10+条）
   - 间隔时间应 > 单条新闻播放时间

### 性能优化

1. **限制新闻数量**：
   - 建议：20-50条新闻
   - 过多（>100条）可能影响随机性能

2. **控制文本长度**：
   - 避免单条新闻超过200字符
   - 过长文本会影响滚动性能
