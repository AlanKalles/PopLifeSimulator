# 滚动播报条系统使用指南（双轨版）

## 概述

滚动播报条系统由两条独立的并行播报条组成：
- **News Ticker**：定时播放随机新闻文本
- **Activity Ticker**：实时播报顾客店内活动

两条播报条互不干扰，同时滚动。

---

## 系统架构

```
ScrollingMessageBar (通用滚动引擎)
  ├── NewsTickerFeeder      → 挂在 News Ticker 上，定时喂新闻
  └── ActivityTickerFeeder  → 挂在 Activity Ticker 上，监听顾客事件
```

### 核心组件

| 组件 | 路径 | 职责 |
|------|------|------|
| ScrollingMessageBar | Scripts/UI/ScrollingMessageBar.cs | 通用滚动引擎（队列+动画） |
| NewsTickerFeeder | Scripts/UI/NewsTickerFeeder.cs | 新闻数据源（定时插入） |
| ActivityTickerFeeder | Scripts/UI/ActivityTickerFeeder.cs | 顾客活动数据源（事件驱动） |
| NewsLibrary | Scripts/UI/NewsLibrary.cs | 新闻文本库 ScriptableObject |

---

## 快速设置

### News Ticker 设置

1. 创建 GameObject（如 `NewsTickerBar`）
2. 添加 `ScrollingMessageBar` 组件，配置 UI 引用（maskRect、messageContainer、messageText）
3. 添加 `NewsTickerFeeder` 组件
4. 将 `NewsLibrary` 资产拖入 NewsTickerFeeder 的 `newsLibrary` 字段
5. 确保 `Enable Random News` 已勾选

### Activity Ticker 设置

1. 创建 GameObject（如 `ActivityTickerBar`）
2. 添加 `ScrollingMessageBar` 组件，配置 UI 引用
3. 添加 `ActivityTickerFeeder` 组件
4. 无需额外配置——自动监听 CustomerEventBus 事件

### UIManager 配置

在 UIManager Inspector 中设置：
- `News Ticker` → 拖入 News 播报条的 ScrollingMessageBar
- `Activity Ticker` → 拖入 Activity 播报条的 ScrollingMessageBar

---

## Activity Ticker 播报事件

| 事件 | 消息格式 | 触发时机 |
|------|----------|----------|
| 进店 | `{Name} entered the store` | 顾客生成（OnSpawned） |
| 拿货 | `{Name} picked {ShelfName}` | 顾客从货架取货（OnPurchased） |
| 结账 | `{Name} spent ${amount}` | 顾客在收银台结账（OnCheckedOut） |

顾客名字通过 `CustomerAgent.GetCustomerRecord().name` 获取，确保名字正确显示。

---

## News Ticker 配置

### NewsLibrary 资产

1. 右键 Project → Create → PopLife → UI → News Library
2. 在 Inspector 中添加新闻文本
3. 配置时间间隔（Min/Max Insert Interval）

### 时间间隔建议

| 节奏 | Min | Max |
|------|-----|-----|
| 慢节奏 | 10s | 30s |
| 正常 | 5s | 15s |
| 快节奏 | 3s | 8s |

## 运行时 API

### 通过 UIManager

```csharp
// 向新闻条添加消息
UIManager.Instance.ShowNewsMessage("Breaking: Record sales today!");

// 向活动条添加消息
UIManager.Instance.ShowActivityMessage("VIP customer arrived!");

// 清空所有播报条
UIManager.Instance.ClearScrollingMessages();

// 兼容旧接口（等同于 ShowNewsMessage）
UIManager.Instance.ShowScrollingMessage("message");
```

### 通过 NewsTickerFeeder

```csharp
var feeder = GetComponent<NewsTickerFeeder>();
feeder.InsertNewsManually("Special announcement!");
feeder.SetRandomNewsEnabled(false);
feeder.SetNewsLibrary(newLibrary);
```

## UI 布局参考

```
┌──────────────────────────────────────────────┐
│ [NEWS]  Breaking News: Local adult store...  │  ← News Ticker（上）
├──────────────────────────────────────────────┤
│ [LIVE]  Alice picked Luxury Vibrator         │  ← Activity Ticker（下）
└──────────────────────────────────────────────┘
```

每条播报条需要的 UI 结构：
```
TickerBar (GameObject)
  ├── Mask (RectTransform + Mask + Image)
  │   └── MessageContainer (RectTransform)
  │       └── MessageText (TextMeshProUGUI)
  ├── ScrollingMessageBar (Component)
  └── NewsTickerFeeder 或 ActivityTickerFeeder (Component)
```

---

## 阶段控制

- **BuildPhase 开始**：两条播报条自动清空队列
- **OpenPhase**：两条播报条正常工作
- 非 OpenPhase 时滚动暂停
