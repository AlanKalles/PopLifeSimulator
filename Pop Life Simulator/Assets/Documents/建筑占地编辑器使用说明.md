# Building Footprint Pattern Editor 使用说明

## 概述

可视化编辑器工具，用于快速设置 `BuildingArchetype` 的占地模板（`footprintPattern`），无需手动输入坐标。

## 坐标系统

```
Y轴 ↑
    │
  3 │ ░ ░ ░ ░
  2 │ ░ ░ ░ ░
  1 │ ░ ░ ░ ░
  0 │ ● ░ ░ ░  → X轴
    └─────────
      0 1 2 3
```

- **锚点（●）**：位于 **(0, 0)** 左下角，显示为**绿色格子**
- **X轴**：向右递增（0 → 1 → 2...）
- **Y轴**：向上递增（0 → 1 → 2...）
- **所有坐标为非负整数**

## 使用步骤

### 1. 打开编辑器
1. 在 Project 窗口选择任意 `BuildingArchetype` ScriptableObject
2. Inspector 底部自动显示 **Footprint Pattern Editor**

### 2. 编辑占地

#### 方法A：点击编辑
- 点击灰色格子 → 变为蓝色（添加占地）
- 点击蓝色格子 → 变为灰色（移除占地）
- 左下角前4行4列显示实际坐标

#### 方法B：快速填充矩形
1. 点击 **"填充矩形"** 按钮
2. 输入参数：
   - **宽度**：横向格子数
   - **高度**：纵向格子数
   - **锚点坐标**：起始位置（默认 0,0）
3. 点击 **"填充"**

### 3. 保存修改
点击 **"应用并保存"** 按钮，将网格状态写入 ScriptableObject

### 4. 其他操作
- **清空**：一键清除所有占地

## 示例

### 示例1：2×2 正方形建筑

- 点击 (0,0), (1,0), (0,1), (1,1)
- 或使用"填充矩形"：宽度2，高度2，锚点(0,0)

### 示例2：L型建筑
```
Y
│
2 │ ■

0 │ ■ ■  → X
  └─────
    0 1
```
- 手动点击：(0,0), (1,0), (0,1), (0,2)

### 示例3：T型建筑
```
Y
│
1 │ ■ ■ ■
0 │   ■    → X
  └───────
    0 1 2
```
- 手动点击：(1,0), (0,1), (1,1), (2,1)

## 技术细节

### 与游戏运行时对应关系
编辑器中的坐标直接对应 `FloorGrid` 系统：

```csharp
// FloorGrid.cs 中的占地检测
foreach (var offset in footprintPattern)
{
    var cell = origin + offset;  // origin是建筑放置的锚点
    if (grid[cell.x, cell.y].occupied) return false;
}
```

### 坐标转换
- **编辑器屏幕坐标**（左上角为原点，Y向下）
- **Footprint坐标**（左下角为原点，Y向上）
- **Unity世界坐标**（`GridToWorld()` 转换）

转换公式：
```csharp
Footprint.X = 网格X - 0
Footprint.Y = (GRID_SIZE-1) - 网格Y
```

## 快捷键（未来扩展）
- [ ] Ctrl+Z / Ctrl+Y：撤销/重做
- [ ] Shift+点击：矩形选择
- [ ] Alt+点击：对称填充

## 已知限制
1. 最大网格 12×12（可通过修改 `GRID_SIZE` 常量扩展）
2. 不支持负数坐标（符合游戏设计）
3. 每次修改需手动点击"应用并保存"
