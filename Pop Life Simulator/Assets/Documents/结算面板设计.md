# 每日结算面板设计文档

## 概述

全新的每日结算面板（`NewDailySettlementPanel`）替代旧的纯文本面板，提供数据可视化、动画效果和更丰富的游戏反馈。

## 核心功能

### 1. 数字滚动动画
- 所有金额数字从0滚动到最终值
- 使用 EaseOutCubic 缓动曲线（快开始慢结束）
- 配合 `Settlement_Tick` 音效（每0.05秒一次）
- 动画时长约1.2秒

### 2. 每日评级 (S/A/B/C/D)
评分公式（满分100）：
- **利润率** (40分): `Clamp(dailyIncome / totalSale, 0, 1) × 40`
- **顾客数** (30分): `Clamp(customers / target, 0, 1.5) × 20`
  - 目标: Day 1-3 → 5人, Day 4-7 → 10人, Day 8+ → 15人
- **Fame** (20分): `Clamp(fame / target, 0, 1.5) × 13.3`
  - 目标: Day 1-3 → 3, Day 4-7 → 8, Day 8+ → 15
- **盈利** (10分): 净收入 > 0 则得10分

评级阈值: S≥85, A≥70, B≥50, C≥30, D<30

### 3. 对比箭头
与昨日数据对比，显示百分比变化：
- 增长: `+12% ▲` (绿色)
- 下降: `-5% ▼` (红色)
- 无变化: `0% ─` (灰色)
- 无昨日数据: 不显示
- 费用增加特殊处理: 增加显示红色（费用增长是负面的）

### 4. 7天收益趋势折线图
- XChart LineChart 程序化创建
- 三条平滑曲线: Revenue(绿), Expenses(红), Net Profit(蓝)
- X轴: Day N 标签
- 带 Tooltip 和 Legend
- 每次结算时 ClearData + 重新填充

### 5. 商品类别饼图
- XChart PieChart 程序化创建
- 按 ProductCategory 聚合当日收入
- 仅显示有收入的品类
- 自动配色

### 6. 热销 Top 3
- 从 StatsDataManager 获取当日货架收入排行
- 显示: 排名 + 图标 + 名称 + 收入金额
- 无销售时显示提示文本

### 7. 顾客升级列表
- 增强版: 带顾客头像（通过 AppearanceDatabase）
- 跨级升级特殊标记

## 数据流

```
DayLoopManager.OnDailySettlement(DailySettlementData)
  → UIManager.OnDailySettlement()
  → NewDailySettlementPanel.ShowSettlement()
      ├── StatsDataManager.GetCategoryRevenueBreakdown()
      ├── StatsDataManager.GetAllShelfStats()
      ├── SettlementHistoryManager.RecordDay()     [ES3持久化]
      ├── SettlementHistoryManager.GetHistory(7)
      ├── SettlementHistoryManager.GetYesterday()
      ├── ResourceManager.AddFame()
      └── AnimateSettlement() 协程
```

## 历史数据存储

使用 Easy Save 3 (ES3) 持久化：
- 文件: `SettlementHistory.es3`
- 存储位置: `Application.persistentDataPath`（ES3自动管理）
- 最多保留7天历史
- 数据结构: `List<SettlementHistoryEntry>`

## Unity编辑器配置清单

1. 场景中添加 `SettlementHistoryManager` GameObject
2. 创建新结算面板UI层级（建议使用 ScrollRect）
3. 创建 `HotSellerItem` 预制体（含 Rank/Icon/Name/Revenue 子物体）
4. 创建 `LevelUpItem` 预制体（含 Portrait/Text 子物体）
5. 为所有 SerializeField 拖拽赋值
6. 在 AudioConfigSO 中配置 `Settlement_Tick` 和 `Settlement_Grade` 音效
