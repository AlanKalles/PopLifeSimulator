# Shelf List Panel Setup Guide
# 货架列表面板设置指南

## Overview | 概述

本指南将帮助你创建一个专用的货架建造面板，带有双重筛选系统（SelectPage + ProductCategory）。

## 文件说明 | File Overview

已创建的脚本文件：
- `Assets/Scripts/UI/ShelfListPanel.cs` - 货架面板主控制器
- `Assets/Scripts/UI/ShelfListItem.cs` - 货架列表项（正方形按钮）
- `Assets/Scripts/UI/ShelfTooltip.cs` - 货架信息悬浮窗口
- `Assets/Scripts/UI/FilterToggleButton.cs` - 筛选按钮组件
- `Assets/Scripts/UI/FilterToggleGroup.cs` - 筛选按钮组管理器

## 系统特性

✅ **专注货架建造**：只显示 ShelfArchetype，不包含 Facility
✅ **双重筛选系统**：
  - 左侧：SelectPage 标签筛选（Body, Head, Front, Back, MedicineBox, Kinky, All）
  - 顶部：ProductCategory 类别筛选（Lingerie, Condom, Vibrator, Fleshlight, Lubricant, BDSM, Dildo, All）
✅ **智能筛选逻辑**：先应用 SelectPage，再应用 ProductCategory
✅ **多标签支持**：货架可以有多个 SelectPage 标签
✅ **单选切换**：按钮保持高亮状态，点击其他按钮自动取消上一个
✅ **悬浮提示**：鼠标悬停显示详细信息

## Part 1: 创建 FilterToggleButton 预制体

### 重要说明
FilterToggleButton 预制体用于两种场景：
1. **SelectPage 按钮**：每个按钮有独立的 Sprite 图标（在运行时设置）
2. **Category 按钮**：所有按钮共享相同的 Sprite

### Step 1.1: 创建按钮GameObject

**SelectPage 按钮版本**（左侧边栏）：
1. Hierarchy 右键 → **UI → Button - TextMeshPro**，命名为 `FilterToggleButton_SelectPage`
2. 设置 **RectTransform**：
   - Width: 100
   - Height: 100（正方形，适合显示图标）
   - Anchor: Top-Left

**Category 按钮版本**（顶部分类栏）：
1. 创建另一个按钮，命名为 `FilterToggleButton_Category`
2. 设置 **RectTransform**：
   - Width: 80
   - Height: 35
   - Anchor: Top-Left

### Step 1.2: 配置按钮

两种版本配置相同：
- **Button** 组件：
  - Navigation: None
  - Transition: Color Tint
  - Normal Color: `(255, 255, 255, 255)`
  - Highlighted: `(220, 220, 220, 255)`
  - Pressed: `(180, 180, 180, 255)`

- **Image** 组件（背景）：
  - Color: `(77, 77, 77, 255)` 深灰色
  - Sprite:
    - **SelectPage**: 留空或默认（运行时会被自定义图标替换）
    - **Category**: 设置统一的背景 Sprite

### Step 1.3: 配置文本

选中子对象 `Text (TMP)`：

**SelectPage 按钮**：
- Text: "Page"
- Font Size: 12
- Alignment: Bottom - Center
- Pos Y: -10（放在按钮底部）
- Color: White

**Category 按钮**：
- Text: "Category"
- Font Size: 14
- Alignment: Center - Middle
- Color: White

### Step 1.4: 添加脚本

两个版本都添加相同脚本：
- **Add Component** → `FilterToggleButton`
- 拖拽引用：
  - **Button**: 拖入自身 Button 组件
  - **Background Image**: 拖入自身 Image 组件
  - **Label Text**: 拖入子对象 `Text (TMP)`

- 配置颜色：
  - **Normal Color**: `(77, 77, 77, 255)`
  - **Selected Color**: `(80, 112, 144, 255)` 蓝色高亮
  - **Hover Color**: `(102, 102, 102, 255)`

### Step 1.5: 保存为预制体

根据实际使用场景选择：
- **方案1**：创建两个预制体
  - `Assets/Prefab/UIs/FilterToggleButton_SelectPage.prefab`（100x100 正方形）
  - `Assets/Prefab/UIs/FilterToggleButton_Category.prefab`（80x35 长方形）

- **方案2**：只创建一个通用预制体
  - `Assets/Prefab/UIs/FilterToggleButton.prefab`（使用 SelectPage 尺寸）
  - 在面板脚本中为不同用途调整尺寸

## Part 6: 筛选系统工作原理

### 双重筛选逻辑

```csharp
bool ShouldShowShelf(ShelfArchetype shelf)
{
    // 第一层：SelectPage 筛选
    if (selectedSelectPage != null) // 非 "All"
    {
        // Shelf 的 selectPages 数组必须包含选中的 SelectPage
        if (!shelf.selectPages.Contains(selectedSelectPage.Value))
            return false;
    }

    // 第二层：ProductCategory 筛选
    if (selectedCategory != null) // 非 "All"
    {
        // Shelf 的 category 必须匹配
        if (shelf.category != selectedCategory.Value)
            return false;
    }

    return true;
}
```

### 示例场景

**Shelf A**：
- `category`: Condom
- `selectPages`: [Front, Back]

**筛选结果**：
- SelectPage = All, Category = All → ✅ 显示
- SelectPage = Front, Category = All → ✅ 显示（包含 Front）
- SelectPage = Back, Category = All → ✅ 显示（包含 Back）
- SelectPage = Body, Category = All → ✗ 隐藏（不包含 Body）
- SelectPage = Front, Category = Condom → ✅ 显示（同时满足）
- SelectPage = Front, Category = Lingerie → ✗ 隐藏（Category 不匹配）

## Part 8: 常见问题 FAQ

### Q: 筛选按钮没有生成？
A: 检查 `FilterButtonPrefab` 是否正确拖入，检查 `SelectPageButtonContainer` 和 `CategoryButtonContainer` 是否有 Layout Group。

### Q: 多个按钮同时高亮？
A: 检查 `FilterToggleGroup` 是否正确注册到容器 GameObject 上。

### Q: 货架筛选不正确？
A: 检查 ShelfArchetype 的 `selectPages` 数组是否正确设置。

### Q: 按钮文本被截断？
A: 调整 FilterToggleButton 的宽度（建议 100-120）。

### Q: 如何修改每行货架数量？
A: 在 Content 的 Grid Layout Group 中修改 `Constraint Count`。
