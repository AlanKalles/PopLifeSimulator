# Narrative Graph Editor 使用指南
# 叙事对话节点编辑器使用文档

## 📊 概述

Narrative Graph Editor 是一个可视化的节点编辑器，让你能够以图形化的方式创建和编辑对话树，解决了 Unity Inspector 中深层嵌套的问题。

![示意图](编辑器将对话片段显示为可连接的节点)

## 🚀 如何打开编辑器

### 方法1：通过菜单栏
```
Unity菜单栏 → Window → PopLife → Narrative Graph Editor
```

### 方法2：快捷方式
选中一个 NarrativeSO 资产，然后打开编辑器

## 🎨 编辑器界面说明

### 工具栏
- **NarrativeSO 选择器**：选择要编辑的对话资产
- **Auto Layout**：自动排列所有节点
- **Add Node**：添加新的对话节点
- **Save**：保存修改到 NarrativeSO
- **搜索栏**：搜索节点内容（支持ID、说话人、文本内容）
- **Next 按钮**：循环浏览搜索结果
- **Help**：显示操作帮助

### 节点颜色含义
- 🔵 **蓝色节点**：根节点（对话起点）
- ⬛ **灰色节点**：普通对话节点
- 🟢 **绿色节点**：当前选中的节点

### 连接点
- 🟡 **黄色点（右侧）**：输出连接点
- 🔵 **青色点（左侧）**：输入连接点

### 连接线高亮
- 🟢 **绿色连接线**：从选中节点流出的连接（下游）
- 🔵 **青色连接线**：流入选中节点的连接（上游）
- ⬜ **半透明灰色**：与选中节点无关的连接

## 🖱️ 基本操作

### 节点操作
| 操作 | 方法 |
|------|------|
| **选择节点** | 左键点击节点 |
| **移动节点** | 选中后拖拽 |
| **编辑节点** | 双击节点 或 右键→Edit Node |
| **删除节点** | 选中后按 Delete 键 |
| **复制节点** | 右键→Duplicate |

### 连接操作
| 操作 | 方法 |
|------|------|
| **创建连接** | 点击起始节点的黄色点，再点击目标节点的青色点 |
| **删除连接** | 删除目标节点会自动删除相关连接 |

### 画布操作
| 操作 | 方法 |
|------|------|
| **平移画布** | 在空白处拖拽 |
| **右键菜单** | 在空白处右键点击 |

## 🔍 搜索功能

### 搜索范围
- **Segment ID**：搜索节点的唯一标识
- **Speaker Name**：搜索说话人名称
- **Text Content**：搜索对话文本内容

### 使用方法
1. 在工具栏的搜索框输入关键词
2. 匹配的节点会自动高亮并居中显示
3. 点击 "Next" 按钮循环浏览所有搜索结果
4. 搜索结果数量显示在按钮上

## 📝 创建对话树步骤

### 1. 加载 NarrativeSO
在工具栏的对象选择器中选择你要编辑的 NarrativeSO 文件

### 2. 添加节点
- 点击 **"Add Node"** 按钮
- 或右键空白处 → **"Add Node Here"**

### 3. 编辑节点内容
双击节点打开编辑窗口：
- **Segment ID**：节点唯一标识（格式：SEG01, SEG02, SEG03...）
- **Speaker Name**：说话人名称
- **Dialogue Text**：对话内容
- **Speaker Portrait**：角色肖像（可选）
- **Is End Segment**：是否为结束节点
- **Display Duration**：显示时长（0=手动控制）

### 4. 连接节点
1. 点击起始节点的**黄色输出点**
2. 拖拽到目标节点的**青色输入点**
3. 松开鼠标完成连接

### 5. 保存修改
点击工具栏的 **"Save"** 按钮保存到 NarrativeSO

## 🌳 创建分支对话

### 简单分支示例
```
根节点："你想了解什么？"
    ├→ 分支1："如何赚钱"
    ├→ 分支2："如何建造"
    └→ 分支3："跳过教程"
```

### 操作步骤
1. 创建根节点
2. 创建3个子节点
3. 从根节点连接到每个子节点
4. 每个分支可以继续添加后续对话

## 🔧 高级功能

### 自动布局
点击 **"Auto Layout"** 按钮，编辑器会：
- 按层级自动排列节点
- 保持合适的间距
- 避免节点重叠

### 设置根节点
右键任意节点 → **"Set as Root"**
- 根节点会变成蓝色
- 对话将从这个节点开始

### 快速生成 ID
在节点编辑窗口中，点击 **"Generate"** 按钮自动生成唯一 ID

**ID 命名规范：**
- **Segment ID**: SEG01, SEG02, SEG03...（对话片段）
- **Sequence ID**: SEQ01, SEQ02, SEQ03...（对话序列）
- **Narrative ID**: NARR01, NARR02, NARR03...（叙事资产）

系统会自动查找下一个可用的序号，确保ID不重复

## 💡 实用技巧

### 1. 组织复杂对话
- 使用规范的 Segment ID（SEG01, SEG02...）确保一致性
- 对于特殊节点，可在编辑器中添加描述性的 Speaker Name 或 Text 来标识
- 保持节点水平排列便于阅读
- 使用 Auto Layout 快速整理

### 2. 调试对话流程
- 节点显示对话文本预览（前30个字符）
- 连接线显示对话流向
- 可以快速定位问题节点

### 3. 批量操作
- 使用 Duplicate 快速创建相似节点
- 删除节点会自动清理相关连接

## ⚠️ 注意事项

### 保存相关
- 记得点击 **Save** 按钮保存修改
- 编辑器会修改 NarrativeSO 的实际数据
- 建议定期保存避免丢失工作

### 限制说明
- 不能删除根节点（蓝色）
- 不能创建自连接（节点连到自己）
- 支持循环连接（A→B→C→A）

## 🐛 常见问题

### Q: 节点没有显示？
A: 检查 NarrativeSO 是否有 Root Segment 数据

### Q: 连接创建失败？
A: 确保从黄色点拖到青色点，不能反向

### Q: 修改没有保存？
A: 必须点击 Save 按钮，仅移动节点不会自动保存

### Q: 如何处理大型对话树？
A: 使用 Auto Layout 自动排列，或手动分层组织
