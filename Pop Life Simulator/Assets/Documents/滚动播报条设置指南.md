# 滚动播报条UI设置指南

## 概述

本文档说明如何在Unity编辑器中设置滚动播报条UI组件。

## 功能特性

- **自动播报**：顾客结账时自动显示消息 `"{CustomerName} spent ${Amount} in store today"`
- **消息队列**：支持最多10条消息排队播放
- **无缝滚动**：文字从右向左连续滚动，遮罩裁剪
- **UIManager集成**：通过 `UIManager.Instance.ShowScrollingMessage(message)` 手动添加消息

## Unity编辑器设置步骤

### 第一步：创建UI层级结构

在现有的 **Screen Space - Overlay Canvas** 中添加以下层级（两个独立的UI元素）：

```
Canvas (Screen Space - Overlay)
├── ButtonArea (RectTransform + Horizontal Layout Group)
│   ├── Button1 (Image - 占位按钮)
│   ├── Button2 (Image - 占位按钮)
│   ├── Button3 (Image - 占位按钮)
│   ├── Button4 (Image - 占位按钮)
│   └── Button5 (Image - 占位按钮)
└── MessageBar (RectTransform + Image + Mask + ScrollingMessageBar.cs)
    └── MessageContainer (RectTransform)
        └── MessageText (TextMeshProUGUI)
```

**注意**：ButtonArea 和 MessageBar 是两个独立的UI元素，互不影响。

---

### 第二步：配置各层级参数

#### 1. **ButtonArea** (按钮区域 - 独立元素)

- **组件**：RectTransform + Horizontal Layout Group
- **RectTransform 设置**：
  - Anchor Presets: **Bottom-Left** (左下角)
  - Pos X: `10` (左边距)
  - Pos Y: `10` (底部边距)
  - Width: `350` (5个按钮 × 60 + 间距 × 4 × 15)
  - Height: `70` (可调整)
- **Horizontal Layout Group 设置**：
  - Child Alignment: `Middle Left`
  - Spacing: `15`
  - Child Force Expand: 均不勾选
  - Padding: 全部设为 `0`

##### 按钮 (Button1 ~ Button5)

- **组件**：Image + Layout Element
- **Image 设置**：
  - Color: `灰色` (占位颜色)
- **Layout Element 设置**：
  - Preferred Width: `60`
  - Preferred Height: `60`

---

#### 2. **MessageBar** (播报条容器 - 独立元素)

- **组件**：RectTransform + Image + Mask + ScrollingMessageBar.cs
- **RectTransform 设置**：
  - Anchor Presets: **Bottom-Stretch** (底部拉伸，自动适应宽度)
  - Left: `370` (左边距，为按钮区域留出空间：350宽度 + 20间距)
  - Right: `10` (右边距)
  - Pos Y: `10` (底部边距)
  - Height: `70` (可调整)
- **Image 设置**：
  - Color: `黑色，Alpha = 150` (半透明深色背景，例如 #000000，然后拖动Alpha滑块到150)
  - Source Image: `None` (可选，使用纯色背景)
- **Mask 设置**：
  - Show Mask Graphic: ✅ (勾选，这样才能看到背景)
- **ScrollingMessageBar 脚本参数**：
  - Message Container: **拖入 MessageContainer 对象**
  - Message Text: **拖入 MessageText 组件**
  - Mask Rect: **拖入 MessageBar 自身的 RectTransform**
  - Scroll Speed: `50` (像素/秒)
  - Message Spacing: `100` (像素)
  - Max Queue Size: `10`

---

#### 3. **MessageContainer** (文字容器)

- **组件**：RectTransform
- **RectTransform 设置**：
  - Anchor Presets: **Middle-Left**
  - Pivot: `(0, 0.5)` (左中心点)
  - Pos X: `0`
  - Pos Y: `0`
  - **Pos Z: `0`** (重要！必须为0)
  - Width: `自动` (由子元素决定)
  - Height: `70` (和MessageBar一样高)

---

#### 4. **MessageText** (文字组件)

- **组件**：TextMeshProUGUI
- **RectTransform 设置**：
  - Anchor Presets: **Middle-Left**
  - Pivot: `(0, 0.5)`
  - Pos X: `0`
  - Pos Y: `0`
  - **Pos Z: `0`** (重要！必须为0，否则可能被Mask裁剪)
  - Width: `自动` (由文字内容决定)
  - Height: `自动` (由文字内容决定)
- **TMP 设置**：
  - Font Size: `24` (可调整)
  - **Color: `白色 (R=255, G=255, B=255, A=255)`** (重要！确保完全不透明)
  - Vertex Color: `白色`
  - Alignment: `Left + Middle`
  - **Overflow: `Overflow`** (重要！允许文字超出容器)
  - **Wrapping: `Disabled`** (重要！不换行)
  - Auto Size: 不勾选
  - Extra Settings > Margins: 全部设为 `0`

---

### 第三步：关联到UIManager

1. 在场景中找到 **UIManager** GameObject
2. 选中后在 Inspector 面板找到 **UI Manager (Script)** 组件
3. 将 **MessageBar** GameObject 拖入 `Scrolling Message Bar` 字段

## 重要：MessageBar配置检查清单

### ✅ MessageBar背景颜色配置（必做！）

如果MessageBar看不见没有颜色，请按以下步骤操作：

1. **选中MessageBar** → 在Inspector中检查是否有 **Image** 组件
2. 如果**没有Image组件**：
   - 点击 `Add Component` → `UI` → `Image`
3. 配置 **Image** 组件：
   - **Color**: 点击颜色框，输入 `#000000`（黑色）
   - **Alpha滑块**: 拖动到 `150-200` 之间（半透明）
   - **Source Image**: 保持 `None`（使用纯色）

**验证方法**：设置完成后，Scene视图中应该能看到一个半透明黑色矩形。

---

### ✅ Mask裁剪问题解决（必做！）

如果勾选Mask后MessageText看不见，请逐项检查：

#### 检查项1：层级结构必须正确
```
MessageBar (有Mask组件)
└── MessageContainer        ← 必须是MessageBar的直接子对象
    └── MessageText         ← 必须是MessageContainer的子对象
```

#### 检查项2：所有Z轴坐标必须为0
- **MessageContainer**: Pos Z = `0`
- **MessageText**: Pos Z = `0`
- **如果Z轴不为0，Mask会失效！**

#### 检查项3：MessageText颜色必须不透明
- Color: 白色 `(255, 255, 255, 255)`
- Alpha: `255` (完全不透明)

#### 检查项4：Mask组件设置
- **Show Mask Graphic**: ✅ 必须勾选

#### 检查项5：Overflow必须设置正确
- TextMeshProUGUI → **Overflow**: `Overflow`
- **Wrapping**: `Disabled`

#### 临时测试方法
1. 在MessageText的Text Input输入：`TEST MESSAGE 123`
2. **暂时取消勾选** MessageBar的Mask组件
3. 如果能看到白色文字 → Mask配置有问题
4. 如果看不到文字 → 文字本身配置有问题（颜色/Z轴）

## 常见问题

### 1. 文字不滚动？

- 检查 `Message Container` 和 `Message Text` 是否正确分配
- 检查 `Mask Rect` 是否指向 MessageBar 自身

### 2. 文字被裁剪不正确？

- 检查 MessageText 的 **Overflow** 是否设为 `Overflow`
- 检查 MessageBar 是否添加了 **Mask** 组件

### 3. 文字不显示？

- 检查 MessageText 的 **Color** 是否为白色（Alpha = 255）
- 检查 MessageContainer 的 **Anchor** 是否为 Middle-Left
- 检查 MessageText 的 **Pivot** 是否为 `(0, 0.5)`

### 4. 队列消息没有自动播放？

- 检查 ScrollingMessageBar 的 `Scroll Speed` 是否 > 0
- 在 Inspector 中查看 `Current Queue Count`，确认队列有消息

## 参数调整建议

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| Scroll Speed | 50-100 | 速度越大，滚动越快 |
| Message Spacing | 100-200 | 消息间距，防止文字重叠 |
| Font Size | 20-28 | 根据面板高度调整 |
| Panel Height | 80-100 | 底部面板高度 |
| Background Alpha | 100-180 | 背景透明度 |

## 架构说明

### 自动播报流程

```
顾客结账 → CustomerInteraction.TryCheckout()
         → CustomerEventBus.RaiseCheckedOut(agent)
         → ScrollingMessageBar.HandleCustomerCheckout()
         → 格式化消息 → EnqueueMessage()
         → 自动播放队列
```

### 消息队列机制

- 使用 `Queue<string>` 实现FIFO
- 当前消息滚动完成后自动播放下一条
- 队列满时移除最旧消息
