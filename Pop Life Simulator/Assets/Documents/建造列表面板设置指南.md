# Building List Panel Setup Guide
# 建造列表面板设置指南

## Overview | 概述

This guide will help you create a scrollable building list panel with buttons to select buildings for placement.

本指南将帮助你创建一个带有滚动条的建造列表面板，通过按钮选择要放置的建筑。

## 文件说明 | File Overview

已创建的脚本文件：
- `Assets/Scripts/UI/BuildingListPanel.cs` - 主面板控制器
- `Assets/Scripts/UI/BuildingListItem.cs` - 列表项组件

---

## Part 1: 创建 Building List Item 预制体

### Step 1.1: 创建列表项GameObject

1. 在 Hierarchy 中右键 → **UI → Panel**，命名为 `BuildingListItem`
2. 设置 **RectTransform**：
   - Width: 280
   - Height: 80
   - Anchor: Top-Left

### Step 1.2: 配置背景 Image

选中 `BuildingListItem`，在 Inspector 中：
- **Image** 组件：
  - Color: `(50, 50, 50, 200)` 深灰色半透明
  - Sprite: 使用 Unity 默认的 `UISprite` 或自定义背景

### Step 1.3: 添加 Button 组件

在 `BuildingListItem` 上添加 **Button** 组件：
- Navigation: None
- Transition: Color Tint
- Normal Color: `(255, 255, 255, 255)`
- Highlighted: `(200, 200, 200, 255)`
- Pressed: `(150, 150, 150, 255)`

### Step 1.4: 添加建筑图标 (Icon)

1. 右键 `BuildingListItem` → **UI → Image**，命名为 `Icon`
2. 设置 **RectTransform**：
   - Anchor: Left-Middle
   - Width: 60
   - Height: 60
   - Pos X: 40
   - Pos Y: 0
3. **Image** 组件：
   - Preserve Aspect: ✓ 勾选
   - Raycast Target: ✗ 取消勾选（不拦截点击）

### Step 1.5: 添加建筑名称文本 (Name Text)

1. 右键 `BuildingListItem` → **UI → Text - TextMeshPro**，命名为 `NameText`
2. 设置 **RectTransform**：
   - Anchor: Stretch-Middle
   - Left: 80
   - Right: 10
   - Height: 30
   - Pos Y: 10
3. **TextMeshProUGUI** 组件：
   - Text: "Building Name"
   - Font Size: 18
   - Alignment: Left - Middle
   - Color: White
   - Overflow: Ellipsis（文字过长时显示省略号）
   - Raycast Target: ✗ 取消勾选

### Step 1.6: 添加价格文本 (Cost Text)

1. 右键 `BuildingListItem` → **UI → Text - TextMeshPro**，命名为 `CostText`
2. 设置 **RectTransform**：
   - Anchor: Stretch-Bottom
   - Left: 80
   - Right: 10
   - Height: 20
   - Bottom: 10
3. **TextMeshProUGUI** 组件：
   - Text: "$500"
   - Font Size: 16
   - Alignment: Left - Bottom
   - Color: `(255, 255, 0, 255)` 黄色
   - Raycast Target: ✗ 取消勾选

### Step 1.7: 添加脚本组件

选中 `BuildingListItem`，在 Inspector 中：
- **Add Component** → 搜索 `BuildingListItem`
- 拖拽引用：
  - **Icon Image**: 拖入 `Icon` GameObject
  - **Name Text**: 拖入 `NameText` GameObject
  - **Cost Text**: 拖入 `CostText` GameObject
  - **Select Button**: 拖入自身的 `Button` 组件
  - **Background Image**: 拖入自身的 `Image` 组件

### Step 1.8: 保存为预制体

将 `BuildingListItem` 从 Hierarchy 拖入 `Assets/Prefab/UIs/` 文件夹，保存为预制体。

## Part 2: 创建 Building List Panel 主面板

### Step 2.1: 创建面板根对象

1. 在 Hierarchy 中右键 → **UI → Panel**，命名为 `BuildingListPanel`
2. 设置 **RectTransform**：
   - Anchor: Right-Stretch（靠右侧停靠）
   - Width: 320
   - Left: 留空
   - Right: 0
   - Top: 0
   - Bottom: 0
3. **Image** 组件：
   - Color: `(30, 30, 30, 230)` 深灰色背景

### Step 2.2: 添加标题栏（可选）

1. 右键 `BuildingListPanel` → **UI → Panel**，命名为 `Header`
2. 设置 **RectTransform**：
   - Anchor: Top-Stretch
   - Height: 50
   - Top: 0
   - Left: 0
   - Right: 0
3. **Image** 组件：
   - Color: `(40, 40, 40, 255)`

4. 添加标题文本：
   - 右键 `Header` → **UI → Text - TextMeshPro**，命名为 `TitleText`
   - Text: "Building List"
   - Font Size: 24
   - Alignment: Center - Middle
   - Anchor: Stretch-Stretch

### Step 2.3: 添加关闭按钮

1. 右键 `Header` → **UI → Button - TextMeshPro**，命名为 `CloseButton`
2. 设置 **RectTransform**：
   - Anchor: Right-Middle
   - Width: 40
   - Height: 40
   - Pos X: -20
3. **Button** 组件配置：
   - 修改子对象 `Text (TMP)` 的文本为 "X"
   - Font Size: 24
   - Color: Red

### Step 2.4: 创建 Scroll View

1. 右键 `BuildingListPanel` → **UI → Scroll View**，命名为 `ScrollView`
2. 设置 **RectTransform**：
   - Anchor: Stretch-Stretch
   - Top: 60（在标题栏下方）
   - Bottom: 10
   - Left: 10
   - Right: 10

3. **Scroll Rect** 组件配置：
   - **Horizontal**: ✗ 取消勾选（只需要垂直滚动）
   - **Vertical**: ✓ 勾选
   - **Movement Type**: Elastic（弹性滚动）
   - **Inertia**: ✓ 勾选
   - **Scroll Sensitivity**: 20

4. **删除** `Scrollbar Horizontal`（不需要横向滚动条）

5. 配置 `Scrollbar Vertical`：
   - Width: 20
   - Direction: Bottom To Top
   - Handle Rect: 设置为滚动条的 Handle 对象
   - Colors: 可自定义颜色（建议浅灰色）

### Step 2.5: 配置 Viewport 和 Content

**Viewport** 已自动创建，检查设置：
- 确保有 **Mask** 组件（用于遮罩超出区域的内容）
- **Image** 组件可以设置透明或不可见（Color Alpha = 0）

**Content**：
1. 选中 `ScrollView/Viewport/Content`
2. 添加 **Vertical Layout Group** 组件：
   - **Spacing**: 10（列表项之间的间距）
   - **Child Alignment**: Upper Center
   - **Child Force Expand**: Width ✓, Height ✗
   - **Child Control Size**: Width ✓, Height ✓

3. 添加 **Content Size Fitter** 组件：
   - **Vertical Fit**: Preferred Size（自动调整高度）
   - **Horizontal Fit**: Unconstrained

4. 设置 **RectTransform**：
   - Anchor: Top-Stretch
   - Top: 0
   - Left: 0
   - Right: 0
   - Pivot: (0.5, 1) 从顶部开始布局

### Step 2.6: 添加主面板脚本

选中 `BuildingListPanel`（根对象），在 Inspector 中：
- **Add Component** → 搜索 `BuildingListPanel`
- 配置引用：
  - **Panel Root**: 拖入自身 `BuildingListPanel`
  - **Close Button**: 拖入 `CloseButton`
  - **Scroll Rect**: 拖入 `ScrollView` 的 `Scroll Rect` 组件
  - **Content Container**: 拖入 `ScrollView/Viewport/Content`
  - **Item Prefab**: 拖入刚才创建的 `BuildingListItem` 预制体
  - **Construction Manager**: 留空（运行时自动查找）

- 配置参数：
  - **Load Buildings From Resources**: ✓ 勾选
  - **Building Resource Path**: `ScriptableObjects/BuildingArchetype`
  - **Enable Category Filter**: ✗ 可选（如果需要类别筛选则勾选）

### Step 2.7: 测试滚动效果

1. 在 `Content` 下手动添加几个临时测试对象（Image或Panel）
2. 运行游戏，测试滚动条是否正常工作
3. 确认内容能够滚动，滚动条响应正确
4. 测试完成后删除测试对象

## Part 3: 集成到场景

### Step 3.1: 添加到 Canvas

1. 如果场景中没有 Canvas，创建一个：
   - Hierarchy → **UI → Canvas**
   - Canvas Scaler 建议设置为 **Scale With Screen Size**
   - Reference Resolution: 1920x1080

2. 将 `BuildingListPanel` 作为 Canvas 的子对象

### Step 3.2: 创建打开按钮（可选）

1. 在 Canvas 下创建 **UI → Button - TextMeshPro**，命名为 `OpenBuildingListButton`
2. 设置位置（例如屏幕右下角）
3. 修改文本为 "Build" 或 "建造"
4. 在 **Button** 组件的 **OnClick()** 事件中：
   - 点击 **+** 添加事件
   - 拖入 `BuildingListPanel` GameObject
   - 选择函数：`BuildingListPanel → OpenPanel()`

或者也可以在 BuildingListPanel 脚本中设置 **Open Button** 引用此按钮。

### Step 3.3: 连接 ConstructionManager

1. 找到场景中的 `ConstructionManager` GameObject
2. 在 `BuildingListPanel` 的 Inspector 中：
   - **Construction Manager**: 拖入 `ConstructionManager`

## Part 4: 高级配置（可选）

### 类别筛选功能

如果需要按类别筛选建筑（Shelf / Facility）：

1. 在 `BuildingListPanel` 下添加 **UI → Dropdown - TextMeshPro**，命名为 `CategoryDropdown`
2. 放置在标题栏下方或顶部
3. 在 `BuildingListPanel` 脚本中：
   - **Enable Category Filter**: ✓ 勾选
   - **Category Dropdown**: 拖入刚创建的 Dropdown

### 自定义列表项外观

在 `BuildingListItem` 脚本的 Inspector 中可以自定义：
- **Normal Color**: 未选中时的背景颜色
- **Selected Color**: 选中时的高亮颜色
- **Affordable Text Color**: 金钱足够时价格的颜色
- **Unaffordable Text Color**: 金钱不足时价格的颜色（默认红色）

### 动态添加/移除建筑

在代码中可以动态操作建筑列表：

```csharp
// 获取面板引用
BuildingListPanel panel = FindObjectOfType<BuildingListPanel>();

// 添加建筑
panel.AddBuilding(myBuildingArchetype);

// 移除建筑
panel.RemoveBuilding(myBuildingArchetype);

// 刷新显示（金钱变化后）
panel.RefreshItemDisplays();
```

## Part 5: 测试流程

### Step 5.1: 准备测试数据

确保 `Resources/ScriptableObjects/BuildingArchetype/` 文件夹中有建筑原型数据：
- 至少有 3-5 个 ShelfArchetype 或 FacilityArchetype
- 每个原型需要设置：
  - **Display Name**（显示名称）
  - **Icon**（图标 Sprite）
  - **Build Cost**（建造费用）

### Step 5.2: 运行测试

1. **播放游戏**
2. 点击 **打开按钮** 或直接在 Inspector 中调用 `OpenPanel()`
3. 检查列表是否正确显示所有建筑
4. 检查滚动条是否工作正常
5. 测试点击列表项：
   - 列表项应该高亮显示
   - ConstructionManager 应该进入放置模式
   - 鼠标移动时应该显示建筑预览
6. 检查金钱不足时价格文本是否变红

### Step 5.3: 调试技巧

**如果列表为空**：
- 检查 Console 是否有日志 `"Loaded X buildings from Resources/..."`
- 确认 Resources 路径正确
- 确认 ScriptableObject 的类型是 `BuildingArchetype` 的子类

**如果点击没有反应**：
- 检查 `ConstructionManager` 引用是否正确
- 检查 Console 是否有错误信息
- 确认 Button 的 Raycast Target 已勾选

**如果滚动不流畅**：
- 调整 Scroll Rect 的 `Scroll Sensitivity`
- 检查 Content 的 Vertical Layout Group 设置
- 确认 Content Size Fitter 已启用

## 常见问题 FAQ

### Q: 为什么列表项显示不全？
A: 检查 Content 的 **Content Size Fitter** 是否设置为 `Vertical Fit: Preferred Size`。

### Q: 滚动条不显示？
A: 当内容高度小于 Viewport 高度时，滚动条会自动隐藏。可以在 Scroll Rect 中设置 `Visibility: Permanent` 强制显示。

### Q: 如何修改列表项的间距？
A: 在 Content 的 **Vertical Layout Group** 中调整 `Spacing` 值。

### Q: 如何让面板从屏幕外滑入？
A: 使用 DOTween 或修改面板的初始位置，然后在 `OpenPanel()` 中添加动画代码。

### Q: 如何实现多列布局？
A: 将 Content 的 **Vertical Layout Group** 替换为 **Grid Layout Group**，并设置 `Constraint: Fixed Column Count`。
